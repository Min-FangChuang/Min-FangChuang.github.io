Expense Tracker CLI

依 TAICA HW2 規格導向開發作業，將命令列記帳工具從 v1.0 的基礎 CRUD 與 CSV 匯出，演化到 v2.0 的查詢摘要、分類治理、JSON 匯出與資料 schema 升級。

01

作品摘要

本專案以「先寫規格，再依規格實作」為核心。v1.0 先完成新增、查詢、修改、刪除與 CSV 匯出；v2.0 再依延伸需求加入摘要分析、分類清單管理與 JSON 匯出，並保留既有成功路徑。

v1.0

最短可用記帳流程

用 JSON 儲存個人收支紀錄，支援 CLI 新增、列表查詢、編輯、刪除與 CSV 匯出。

v2.0

查詢與資料品質強化

在 list 下方加入 Count、Total Income、Total Expense、Net，並新增 summary 與 category 指令。

Design

保留模組邊界

CLI 解析、service layer、storage、validators、formatter 與 exporter 各自負責單一面向，降低功能演化時的改動範圍。

Compatibility

v1 → v2 隱式升級

v2 storage 將 JSON schema 擴充為 next_id、categories 與 records，並能為舊資料補上預設分類清單。

02

規格導向開發

HW2 要求在既有 v1.0 規格與實作基礎上，閱讀自動產生的 v2.0 延伸需求，撰寫新的 SDD 並完成 v2 實作。重點不是單純加功能，而是讓規格、架構、相容性與實作彼此對齊。

v1 Decision

先穩定核心邏輯

v1.0 選擇標準函式庫 argparse、JSON 檔案與 dataclass 模型，把常見記帳流程做完整，同時保留未來替換輸入層、儲存層與輸出格式的彈性。

v2 Extension

依需求局部擴充

v2.0 沒有重寫整套程式，而是在原本分層上補入 query summary、summary rows、category 管理與 JSON exporter，讓功能升級不破壞既有指令。

03

功能範圍

指令功能v2 重點
add新增收入或支出紀錄。檢查 category 是否在合法分類清單中。
list依 type、category、date、month、keyword 等條件查詢。表格下方附上筆數、收入、支出與淨餘摘要。
summary依 category + type 彙總紀錄。支出列額外顯示 percentage，協助觀察支出結構。
category列出、新增、刪除合法分類。提升分類一致性，避免 food、Food、food 空白等資料分裂。
edit依 id 修改既有紀錄欄位。修改 category 時同樣套用合法分類驗證。
delete依 id 刪除紀錄。保留明確成功/失敗訊息與退出碼語意。
export匯出篩選後的紀錄。保留 CSV，新增 JSON，且匯出 JSON 不包含 next_id 等內部欄位。
常用指令範例
python main.py add --amount 100 --category food --note lunch
python main.py list --type expense --month 2026-03
python main.py summary --month 2026-03
python main.py category --list
python main.py category --add health
python main.py export --format json --output march.json --month 2026-03

04

架構演化

面向v1.0v2.0
儲存層JSON 檔案，管理 next_id 與 records。JSON schema 加入 categories，並支援舊資料隱式遷移。
CLIargparse + add/list/edit/delete/export。新增 summary 與 category subcommands。
查詢輸出表格列出紀錄。表格 + query summary + category summary。
匯出CSV。CSV + JSON。
資料品質category 可自由輸入。category 需存在於合法分類清單。
Core

Service layer

services.py 協調驗證、儲存、過濾、摘要、分類與匯出，是 CLI 與資料層之間的主要業務邊界。

Data

Storage + Models

storage.py 負責初始化、讀寫與 schema 升級；models.py 定義 Item、QuerySummary 與 SummaryRow。

Output

Formatter + Exporter

formatter.py 負責 CLI 表格與摘要輸出；exporter.py 負責 CSV 與 JSON 檔案輸出。
