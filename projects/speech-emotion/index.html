01

作品摘要

本作品目標不是只在單一資料集取得高準確率，而是觀察模型在不同語音情緒資料集之間是否能維持辨識能力。訓練流程分別處理 RAVDESS 與 CREMA-D，並用 GUI 系統把模型選擇、音訊輸入、情緒結果、機率分布、波形與 MFCC 視覺化集中在同一個介面。

Dataset

兩種語音情緒資料集

RAVDESS 以檔名編碼出八種情緒類別；CREMA-D 以檔名中的情緒縮寫整理六種情緒類別。

Feature

以 MFCC 作為模型輸入

每段音訊讀取為 22050 Hz、2.5 秒長度，使用 20 維 MFCC 表示語音特徵。

Model

1D CNN 情緒分類

模型用多層 Conv1d、BatchNorm、ReLU、MaxPool 與 AdaptiveAvgPool1d 萃取時間序列特徵，再輸出情緒類別。

System

可操作推論系統

使用者可選擇六類或八類模型，載入 wav 檔後查看預測結果、各類機率、音訊波形與 MFCC 圖。

資料前處理

音訊轉成固定長度後，分別建立原始、加雜訊與 pitch shift 版本。資料集切分使用 stratified 8:2 train/test split，降低類別比例不均造成的偏差。

模型設計

1D CNN 從 20 維 MFCC 輸入開始，通過多個卷積區塊逐步擴充特徵通道，再以 adaptive average pooling 與全連接層完成分類。

03

模型訓練與正確率分析

兩個模型皆訓練 50 epochs，表格中的最佳 epoch 代表 test split 表現最佳的 checkpoint。RAVDESS 與 CREMA-D 在各自資料集的 test split 上都能取得約 97% 準確率；但跨資料集測試時，非訓練資料集的語音容易被模型集中判成相同情緒，顯示錄音條件、語句內容與情緒標註標準差異會明顯影響泛化。

訓練曲線與 confusion matrix

資料操作上，每筆語音保留原始 waveform，並產生 noise 與 pitch shift 版本，因此訓練資料量擴充為三倍。模型訓練結果用 accuracy curve 觀察收斂情況，再用 confusion matrix 檢查各情緒類別的分類表現。

05

結論與參考資料

兩個模型在各自訓練資料集的測試切分中表現良好；但當輸入改成非訓練資料集時，容易出現多筆音訊被判成相同情緒的情況。這表示 RAVDESS 與 CREMA-D 在錄音環境、語句內容、情緒表達方式與標註標準上的差異，會造成明顯的 domain gap，模型仍需要更多跨資料集校正或資料擴充才能穩定泛化。
