01

作品摘要

這是 114-2 多媒體系統課程作業，目標是理解影片壓縮中 motion estimation 與 motion compensation 的基本流程。程式將相鄰影格切成固定大小的 macroblock，在 reference frame 的搜尋範圍內找出 SAD 最小的位置，形成 motion vector 並重建 compensated frame。

Input

相鄰影格配對

依檔名順序讀取影格，以第 i-1 幀作為 reference frame、第 i 幀作為 current frame。

Search

四種搜尋策略

實作 Exhaustive、2D Logarithmic、Hierarchical，以及作為 bonus 比較的 Diamond Search。

Cost

SAD block matching

以 Sum of Absolute Differences 作為 block matching cost function，選擇差異總和最小的候選位置。

Output

圖像與數值紀錄

輸出 compensated frame、motion vector map，以及每幀 PSNR、total SAD、average search points。

02

方法比較

01

Exhaustive Search

在搜尋範圍內逐一檢查所有候選位置，通常能取得較好的補償品質，但平均搜尋點數最高。

02

2D Logarithmic Search

以搜尋中心與步長縮小進行多階段搜尋，用較少候選點接近可用的 motion vector。

03

Hierarchical Search

利用多解析度影像先估計粗略位移，再回到較高解析度做 refinement，降低全解析度搜尋成本。

04

Diamond Search

使用 Large Diamond 與 Small Diamond 搜尋樣板，嘗試在較低平均搜尋點數下保留接近的補償效果。

03

評估結果

以下為 30 組相鄰影格的平均結果。PSNR 與 total SAD 反映補償品質，average search points 反映每個 macroblock 平均檢查的候選位置數量。

方法Avg PSNRAvg total SADAvg search points觀察
Exhaustive32.4408334470204.2828補償品質最高，搜尋量最大。
Hierarchical32.085834856467.4891以多解析度降低搜尋量，品質介於 Exhaustive 與快速搜尋法之間。
Logarithmic31.956135380039.0144搜尋點數明顯下降，但平均 PSNR 也較低。
Diamond32.179334446821.8216平均搜尋點數最低，PSNR 仍接近 Exhaustive。

整理重點：Exhaustive Search 作為完整搜尋基準，能取得較高 PSNR；Diamond Search 在本次測試中以最低平均搜尋點數取得接近的補償品質，適合用來說明 motion estimation 中品質與運算量的取捨。
